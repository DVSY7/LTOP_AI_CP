# 전기방식 강화학습 프로젝트 작업 지침

## 프로젝트 목적

이 저장소는 외부전원식 전기방식 시스템의 제어를 위한 강화학습 가상환경 프로토타입이다. Gymnasium 환경을 기반으로 이산 행동을 사용하는 DQN 제어와 연속 행동을 사용하는 SAC 제어를 모두 지원한다.

현재 구현은 강화학습 및 제어 흐름을 검증하기 위한 프로토타입으로 취급한다. 검증된 전기화학 모델이나 현장 적용이 가능한 전기방식 시뮬레이터로 간주하지 않는다.

## 언어와 인코딩

- 사용자가 별도로 요청하지 않는 한 한국어로 소통한다.
- 소스 파일과 문서는 UTF-8 인코딩을 사용한다.
- 파일을 수정할 때 기존 한국어 주석과 문자열을 보존한다.
- 물리적 가정과 단위를 명확하게 설명한다.

## 저장소 구성

- `config/settings.py`: 전압, 전류, 전위, 에피소드, 행동, 모델 경로, 알고리즘 및 학습 설정
- `env/cathodic_env.py`: Gymnasium 환경, 관측·행동 공간, 상태 전이, 보상 선택 및 에피소드 처리
- `reward/reward_function.py`: DQN과 SAC에 사용하는 개별 보상함수
- `safety/safety_filter.py`: 요청된 정류기 전압을 설정된 운전 범위로 제한하는 안전 필터
- `models/dqn_model.py`: Stable-Baselines3 DQN 모델 생성 함수
- `models/sac_model.py`: Stable-Baselines3 SAC 모델 생성 함수
- `train.py`: 설정된 알고리즘을 선택하여 모델을 학습하고 저장하는 실행 파일
- `evaluate.py`: 설정된 학습 모델을 불러와 환경에서 평가하는 실행 파일
- `tests/`: 직접 실행할 수 있는 assert 기반 테스트와 Gymnasium 호환성 검사
- `models/trained/`: 저장된 DQN 및 SAC 모델 파일

## 현재 환경 규약

### 상태

환경 내부 상태는 다음 세 값으로 구성된다.

1. 정류기 출력전압 `[V]`
2. 정류기 출력전류 `[A]`
3. 관대지전위 `[mV]`

DQN에는 원시 상태값을 전달한다. SAC에는 설정된 관측 범위를 기준으로 각 상태값을 `[0, 1]` 범위로 정규화하여 전달한다.

### 행동

- DQN: 기본적으로 전압 감소, 유지, 증가에 해당하는 `-0.5/0/+0.5 V`의 이산 행동을 사용한다.
- SAC: `[-1, 1]` 범위의 연속 행동 하나를 출력하며, 여기에 `VOLTAGE_STEP`을 곱한다.
- 안전 필터는 계산된 출력전압을 기본적으로 `0..60 V` 범위로 제한한다.

### 임시 동역학

현재 프로토타입은 다음 상태 변화식을 사용한다.

```text
output_current = clip(output_voltage * 0.1, 0, 30)
pipe_potential_next = clip(
    pipe_potential + applied_delta_voltage * -20,
    -3000,
    0,
)
```

기본 초기 상태를 적용하면 다음 관계로 단순화된다.

```text
output_current = 0.1 * output_voltage
pipe_potential = -500 - 20 * output_voltage
```

따라서 명목상 3차원인 상태는 실질적으로 1차원이다. 별도의 설명이나 단서 없이 이 관계를 현실적인 물리 모델로 표현하지 않는다.

### 에피소드와 목표

- 초기 상태: `10 V`, `1 A`, `-700 mV`
- 목표 전위 구간: `-950..-850 mV`
- 최대 에피소드 길이: 50스텝
- 현재는 성공 또는 위험 상태에 따른 종료 조건이 없으며, 최대 시간 도달에 따른 `truncated`로만 에피소드가 끝난다.

현재 목표 전위에는 기준전극의 종류, ON 전위인지 instant-OFF 전위인지 여부, 적용되는 공학적 판정 기준이 정의되어 있지 않다. 목표 전위를 현장 운용 기준으로 취급하기 전에 반드시 해당 조건을 명시해야 한다.

## 확인된 문제와 한계

프로젝트를 분석하거나 수정할 때 다음 사항을 고려한다.

1. 현재 동역학에는 토양저항, 코팅 상태, 애노드 저항, 분극·탈분극 지연, IR drop, 환경 외란, 측정 노이즈 및 통신 지연이 없다.
2. 전압 유지 행동을 선택하면 관대지전위가 영구적으로 고정된다. 전위 완화나 탈분극 거동이 없다.
3. 설정상 최대전류는 30 A이지만 현재 전류식과 최대전압으로는 6 A까지만 도달할 수 있다.
4. 관측공간의 전위 범위는 `-3000..0 mV`이지만 기본 초기 상태와 허용 전압 범위에서 실제 전위는 대략 `-500..-1700 mV`로 제한된다.
5. 초기화 과정은 결정론적이다. 무작위 초기 상태나 외란이 없으므로 현재 `seed`는 실질적인 영향을 주지 않는다.
6. 보상값은 `-850 mV`와 `-950 mV` 경계에서 급격하게 변한다. 이 불연속성으로 인해 정책이 경계값을 과도하게 추종하거나 진동할 수 있다.
7. SAC 보상함수의 주석은 목표 중심을 언급하지만 실제 구현은 `TARGET_POTENTIAL_MAX`, 즉 `-850 mV`를 진행 보상의 목표로 사용한다. 목표 구간의 중심이 의도라면 `-900 mV` 또는 두 경계의 중간값을 사용해야 한다.
8. 안전 필터는 전압만 제한한다. 관대지전위, 전류, 전력, 변화율, 센서 유효성 및 고장 안전 조건은 적용하지 않는다.
9. 행동 패널티는 실제 적용된 행동을 기준으로 계산한다. 전압 한계에서는 적용 변화량이 0이 되므로 에이전트가 불가능한 행동을 반복 요청해도 패널티가 발생하지 않을 수 있다.
10. DQN과 SAC는 서로 다른 보상함수를 사용하므로 두 모델의 에피소드 누적 보상을 직접 비교할 수 없다.
11. `evaluate.py`는 500 평가 스텝을 요청하지만 환경은 50스텝에서 종료된다.
12. 모델과 출력 파일 경로는 현재 작업 디렉터리를 기준으로 하는 상대경로이다.

## 마지막으로 검증한 모델 동작

현재 저장된 모델을 결정론적으로 50스텝 평가한 결과는 다음과 같다.

- DQN: `17.5 V`, `-850 mV`에 도달한다. 15스텝 동안 전압을 증가시킨 후 유지하며, 전체 50스텝 중 36스텝을 목표 구간에서 보낸다.
- SAC: 약 `19.46 V`, `-889.24 mV`에서 종료한다. 전체 50스텝 중 25스텝을 목표 구간에서 보내며, 평가 후반에는 크기가 비슷한 양수·음수 행동을 번갈아 선택하여 작은 진동을 만든다.

동역학, 보상, 정규화 또는 모델 하이퍼파라미터를 변경한 후에는 이 검증을 다시 실행한다. 환경 규약이 변경되면 기존 저장 모델은 호환되지 않거나 잘못된 결과를 낼 수 있으므로 일반적으로 다시 학습해야 한다.

## 테스트와 실행 환경 참고사항

저장소의 `.venv`는 다른 환경에서 사용할 수 없는 상태다. `.venv/pyvenv.cfg`가 현재 다른 사용자의 `C:\Users\gbytk\...` 경로에 있는 Python을 가리키므로 현재 컴퓨터에서 실행할 수 없다.

마지막 분석에서 확인한 시스템 Python 환경은 다음과 같다.

- Python 3.13.14
- Gymnasium 1.3.0
- Stable-Baselines3 2.9.0
- NumPy 2.5.1

마지막 분석 당시 `pytest`는 설치되어 있지 않았다. 다음 테스트 스크립트를 각각 직접 실행했으며 모두 통과했다.

```powershell
python tests/test_setting.py
python tests/test_reset.py
python tests/test_step.py
python tests/test_safety.py
python tests/test_episode.py
python tests/test_env_checker.py
python tests/test_dqn.py
python tests/test_sac.py
```

현재 `requirements.txt` 또는 `pyproject.toml`이 없다. 재현 가능한 의존성 명세와 깨끗한 실행 환경을 구성하는 작업을 우선한다. 특정 컴퓨터에 종속된 가상환경을 사용하거나 저장소에 커밋하지 않는다.

## 변경 작업 지침

- Gymnasium API를 유지한다. `reset()`은 `(observation, info)`를 반환하고, `step()`은 `(observation, reward, terminated, truncated, info)`를 반환해야 한다.
- 관측값은 선언된 관측공간 안에 있어야 하며 `numpy.float32` 자료형으로 반환한다.
- 이산 및 연속 행동 모드 모두에 대해 행동의 형태, 자료형과 범위를 검증한다.
- 변수명, 주석, 문서 및 테스트 사례에 공학 단위를 명시한다.
- 상태 동역학을 변경하면 관측 범위와 관련 테스트를 함께 수정한다.
- 행동 또는 관측 규약을 변경하면 저장된 DQN과 SAC 모델을 모두 다시 학습한다.
- 보상 경계, 연속 행동, 안전 필터 개입 및 물리 상태 불변조건에 대한 단위 테스트를 추가한다.
- 안전 처리를 확장할 때 요청 행동과 실제 적용 행동을 구분하여 `info`에 기록한다.
- 물리 상수를 코드에 직접 작성하기보다 설정값으로 매개변수화한다.
- 기준전극, 측정 방법, 적용 표준 및 검증 데이터가 명시되지 않은 상태에서 현장 안전성이나 표준 준수를 주장하지 않는다.
- 사용자의 관련 없는 변경사항을 보존하며, 작업 요청에 재학습이 포함되지 않은 경우 학습된 모델 파일을 교체하지 않는다.

## 권장 개발 순서

1. 의존성 명세 파일을 추가하고 실행 환경 구성 방법을 문서화한다.
2. 물리 모델의 적용 범위, 기준전극, ON/OFF 측정 방식, 스텝당 시간, 제어 대상 설비 및 공학적 성공·안전 기준을 정의한다.
3. 현재 임시 상태 전이식을 매개변수화된 동적 모델로 교체한다.
4. 토양, 코팅, 부하, 노이즈, 지연 및 초기 상태를 무작위화한 시나리오를 추가한다.
5. 보상함수를 연속적으로 만들고 과방식 및 안전하지 않은 행동에 대한 비용을 명시적으로 추가한다.
6. 안전 계층을 전류, 전력, 전위, 변화율 및 유효하지 않은 측정값까지 확장한다.
7. PID 또는 규칙 기반 기준 제어기를 추가하고 목표 구간 체류율, 에너지, 안정화 시간, 오버슈트, 위험 상태 지속시간 및 강건성을 비교한다.
8. 최종 모델을 다시 학습하기 전에 자동화된 학습·평가 시드, 체크포인트, 지표 및 회귀 테스트를 추가한다.

- 코드 인터페이스 검증과 물리 모델 검증을 명확하게 구분한다.
